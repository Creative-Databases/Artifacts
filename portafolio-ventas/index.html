Digitalización 101 · Ecosistema Claris

FileMaker Cloud vs. FileMaker Server

Dos formas de alojar el sistema. La diferencia es cuánto control necesitas.

cloud

FileMaker Cloud

Claris aloja y administra el servidor por ti.

  • Actualizaciones y respaldos gestionados por Claris
  • Inicio de sesión con Claris ID
  • Mínima configuración — conveniencia primero
  • A cambio: menos control fino (plugins de servidor, configuración avanzada, acceso a la infraestructura)
dns

FileMaker Server

El servidor completo, bajo control total — tuyo o administrado por nosotros.

  • Control de versión, configuración y momento de actualizar
  • Plugins, scripts de servidor e integraciones sin restricciones
  • Respaldos a la medida + resiliencia (respaldo externo, servidor en espera)
  • Con nuestro hosting administrado: el control total, sin que tú lo administres

Nuestra postura: para operaciones serias solemos recomendar FileMaker Server administrado — el control importa cuando el sistema ES tu operación. Pero depende de tu caso, y te lo explicamos con trade-offs en la sesión de exploración.
